Al clonar el repositorio el usuario debera ejecutar el comando

pip install -r requirements.txt

Con ello obtendra la mayoria de recursos que se requieren para que la aplicación funcione.

Tambien el usuario debera ejecutar el comando 

winget install ffmpeg 

Finalizando la descarga de recursos necesarios.

Finalmente deberá ejecutar el comando 

python ./app.py
